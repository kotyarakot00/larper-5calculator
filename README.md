# ⏱️ YouTube 5-Letter Words Video Calculator

Абсолютно безумный калькулятор таймкодов и экранных координат для легендарного 108-часового YouTube-видео **«ВСЕ СЛОВА ИЗ ПЯТИ БУКВ В ОДНОМ ВИДЕО»** от автора *larper2004*.

## 🚀 О проекте

Видео длится **108 часов, 42 минуты и 34 секунды**. Оно представляет собой полный математический перебор всех возможных комбинаций из 5 букв русского алфавита ($33^5 = 39\ 135\ 393$ слов). 

Каждый кадр видео меняется ровно раз в секунду и отображает сетку из **100 слов (10 строк на 10 столбцов)**. Этот скрипт использует чистую математику, чтобы мгновенно найти точный таймкод любого слова и автоматически открыть его в вашем браузере.

## 🛠️ Возможности скрипта

- **Мгновенный расчет:** Переводит любое 5-буквенное слово в точное время с точностью до секунды.
- **Экранный навигатор:** Показывает конкретную строку (1-10) и столбец (1-10), где расположено слово.
- **Интеграция с YouTube:** Автоматически генерирует рабочую ссылку и открывает её в браузере по умолчанию прямо на нужном моменте.

## 💻 Как запустить у себя

1. Установите **Python 3.10+**.
2. Скачайте файл из этого репозитория.
3. Введите любое слово из 5 русских букв (например, `хомяк` или `иувег`) и нажмите **Enter**.

## 📊 Пример работы математики

Для слова `ЁПТАА`:
- **Таймкод:** 21:25:12
- **Позиция:** строка 1, столбец 10
